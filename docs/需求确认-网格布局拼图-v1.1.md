## 1. 一句话定义

在现有「横向拼接 / 纵向拼接」之外，新增第三种拼接方式 **「网格拼接」**：
用户可以设置 **行数 × 列数**（如 3×3）以及 **行间距 / 列间距**，图片按顺序填入网格；
可以把若干相邻格子 **合并成一个大矩形格**（大格只放 1 张图，其余图片继续按顺序往后填）；
并且可以在 **预览中直接拖动图片对调位置**，底部缩略图的顺序/序号同步更新。
其余能力（外边距、背景色与透明度、输出尺寸、PNG/JPG、保存、单实例、右键菜单）全部沿用现有 v1.0.0 行为。

## 2. 背景、现状与目标

### 2.1 现状（v1.0.0）
- 免安装单文件 exe（.NET Framework 4.8 / WinForms / C# 5 / 无第三方库）；
- 右键「拼图」→ 编辑器；底部缩略图列表可拖动排序、删除、清空；横向/纵向实时预览；
- 间距、外边距、背景色+透明度、输出尺寸（自动/指定宽高）、PNG/JPG、设置记忆；
- 布局引擎 `LayoutEngine`（纯计算）+ 合成器 `Compositor`（GDI+ ARGB）。
- 现有文档曾把「九宫格/自由布局/模板」列为暂不做。**本次按新需求解禁「网格拼接」**，
  仍不做自由布局、模板库。

### 2.2 本次目标
| 目标 | 说明 |
|---|---|
| 新增网格模式 | 行列可设、图片顺序填充、末尾空格留空 |
| 行/列间距独立 | 网格模式下行间距、列间距分别可调（外边距保留） |
| 合并单元格 | 相邻格子合并为矩形大格，大格只放 1 张图；可拆分/清空 |
| 预览拖动换图 | 预览里拖动两张图对调，底部缩略图顺序与序号同步 |
| 向后兼容 | 横向/纵向行为与输出零变化；旧配置可读；版本升至 v1.1.0 |
| 保持轻量 | 单文件 exe、无新依赖、界面中文、实时预览；新增代码由本机 csc 编译 |

## 3. 需求拆解（原始需求 → 可验收功能点）

### R1 网格布局
- R1.1 拼接方式增加第三种「网格」；横向/纵向保持现状。
- R1.2 网格模式可设置行数、列数（见 Q1：推荐行/列分别设置，范围各 1–20，默认 3×3）。
- R1.3 图片按顺序填入网格（见 Q2：推荐从左到右、从上到下）。
- R1.4 最后一行（及任意位置）未填满的格子**留空**：保持网格几何，空位显示背景色/透明（预览为棋盘格）。
- R1.5 网格数量与图片数量不一致时都成立：图片少于格子 → 后面留空；图片多于容量 → 见 R3.5。
- R1.6 空网格（0 张图）时仍可设置行列/合并，预览显示空状态提示。

### R2 行间距 / 列间距
- R2.1 网格模式下提供「行间距」「列间距」两个 0–200 px 的设置（默认均 12，与现有「图片间距」默认值一致）。
- R2.2 外边距继续有效（图片网格整体四周留白），默认 16。
- R2.3 网格模式的几何：`画布宽 = 2×外边距 + 列数×单元格宽 + (列数-1)×列间距`，高同理。
- R2.4 横向/纵向模式继续使用现有「图片间距」（不受影响）。
- R2.5 间距为 0 时相邻格子/图片之间不能出现 1px 缝隙（沿用 v1 的“边界取整”处理）。

### R3 合并单元格（大格）
- R3.1 可将若干**相邻**格子合并成一个**矩形**大格（2×1、1×2、2×2、1×3、3×2 等）。
- R3.2 合并后的大格只放 **1 张**图；图片按顺序先填大格，再继续填后面的格子（顺序不变，见 4.2）。
- R3.3 大格内的图片按 R4 规则等比完整显示；大格跨越的格子之间原有的行/列间距不再保留（大图是一整块）。
- R3.4 支持「拆分」已合并的大格（恢复为单个格子），以及「清空所有合并」。
- R3.5 合并会减少总容量（容量 = 格子总数 − Σ(合并区域面积 − 1)）。若容量小于图片数量，多余图片**不放入网格**，
  但仍保留在底部列表并标记「未放入」，状态栏提示（见 Q6 推荐）。
- R3.6 合并区域不能超出网格、不能互相重叠、必须是矩形；不允许“L 形”等非矩形合并。
- R3.7 调整行数/列数后，仍在范围内的合并保留；越界的合并自动移除，并给出提示。
- R3.8 合并/拆分/清空后，预览与输出立即刷新；不删除、不打乱图片顺序。
- R3.9 合并结构是否跨启动记忆见 Q7（推荐记忆，与行列数、间距一起保存，并可一键清空）。

### R4 预览拖动换图
- R4.1 在预览区按住某张图片拖动，松手到另一张图片上 → 两张图片**对调**顺序（大格与小格之间同样适用）。
- R4.2 底部缩略图列表的顺序、序号同步更新（对调后两张图的序号互换），选中状态跟随。
- R4.3 拖动时给出明确反馈：源图半透明/高亮，目标格高亮描边，鼠标指针变化，状态栏提示「交换 第2张 ↔ 第5张」。
- R4.4 拖到空白格、棋盘格空白区或无效位置 → 取消操作（不改变顺序）。按 Esc 取消拖动。
- R4.5 加载中/保存中/无图时不响应拖动；拖动结束松手后才重算预览（避免拖动过程闪烁）。
- R4.6 默认三种拼接方式都支持预览拖动换图（见 Q8）；横向/纵向模式下同样是“两张图对调”。
- R4.7 缩略图栏原有的拖动排序（插入移动）保持不变，两种排序入口互不冲突。

### R5 兼容、记忆与交付
- R5.1 设置记忆新增：拼接方式=网格、行数、列数、行间距、列间距、合并结构（按 Q7）、（可选）单元格显示模式。
- R5.2 旧版 `settings.ini` 无这些键时使用默认值，不报错；新版写回的配置旧版可忽略未知键。
- R5.3 横向/纵向的布局、预览、保存、CLI 输出结果必须与 v1.0.0 完全一致（回归测试）。
- R5.4 命令行 `--compose` 增加网格参数，供自动化测试/脚本使用（见 5.5）。
- R5.5 版本号升至 **v1.1.0**，同步更新 README、使用说明、接口契约、验收报告与发布包命名。
- R5.6 构建方式不变（系统 csc，无新引用、无第三方 DLL、无新网络行为）。

## 5. 核心规则与算法（开发依据）

### 5.1 术语
| 术语 | 含义 |
|---|---|
| 单元格 / 格子 | 网格中的最小矩形单元；所有单元格等大 |
| 合并区域 / 大格 | 由若干相邻单元格合并成的矩形区域；只放 1 张图 |
| 区域（Region） | 填图单位：单个格子或合并区域 |
| 容量 | 区域总数；决定最多能放入多少张图 |
| 填入顺序 | 区域按“行优先”排序后依次对应图片顺序 |

### 5.2 填图顺序与容量
设行数 R、列数 C、合并区域集合 M（每个区域用 `(r0,c0)-(r1,c1)` 表示，0 基、闭区间）。

1. 区域 = 未被任何合并覆盖的单个格子 + 每个合并区域。
2. 区域按 `(r0, c0)` 行优先排序（先比行，再比列）。
3. 第 i 张图片（i 从 0 开始）放入第 i 个区域，i < 容量；i ≥ 容量 的图片不放入。
4. 容量 `K = R*C − Σ((r1−r0+1)*(c1−c0+1) − 1)`。
5. 空区域（没有对应图片）留空，保留几何位置（背景色/透明）。

> 示例：3×3 网格、把左上 2×2 合并 → 区域顺序：大格(0,0)、格(0,2)、格(1,2)、格(2,0)、格(2,1)、格(2,2)，容量 6；
> 5 张图时：图 1 进大格，图 2..5 进后 4 格，最后一格(2,2)留空。

### 5.3 单元格几何
设单元格宽 `cw`、高 `ch`，列间距 `cg`、行间距 `rg`，外边距 `m`：

```
x(c) = m + c * (cw + cg)
y(r) = m + r * (ch + rg)
```

- 区域 `(r0,c0)-(r1,c1)` 的矩形：
  - `X = x(c0)`，`Y = y(r0)`
  - `W = (c1-c0+1)*cw + (c1-c0)*cg`（含跨越的内部列间距，大图连续无裂缝）
  - `H = (r1-r0+1)*ch + (r1-r0)*rg`
- 画布：`CW = 2m + C*cw + (C-1)*cg`，`CH = 2m + R*ch + (R-1)*rg`。
- 所有坐标用整数像素计算；缩放输出时沿用现有“边界取整”策略，保证 0 间距时无缝隙/无重叠。

### 5.4 单元格内图片的显示（已确认：等比完整显示、不裁切）
- 图片等比缩放到“完整放进所在区域”，居中显示；**不拉伸变形、不裁切**（与产品现有原则一致）。
- 图片小于区域时会放大（与现有横向/纵向“统一基准”行为一致），预览与保存效果一致。
- 图片自身的 Alpha 完整保留；区域剩余空间显示背景色/透明。
- 「填满裁切」模式本期**不做**（Q3 确认只做完整显示），后续如需再加。

### 5.5 输出尺寸与尺寸保护
- **自动**（默认）：单元格宽、高分别取所有图片宽、高的中位数（偶数取中间两个平均；单图即原图尺寸），
  再按 5.3 计算画布；与现有横向/纵向的“自动=中位数”语义一致。
- **指定宽度 / 指定高度**：先按自动算出自然布局，再整体等比缩放到目标画布宽/高（间距、边距、单元格同步缩放），
  与现有两种模式的语义、界面提示一致。
- **尺寸保护**：沿用总像素 8000 万、单边 32000 px；超限时自动缩小单元格并提示「已自动缩小」（WasClamped），
  空位/间距/边距不改变用户设置。
- 网格模式不使用旧的「自定义基准尺寸」（BaseSize）；如 CLI 传入 `--base`，仅对横向/纵向生效。

### 5.6 合并合法性
- 选区必须是网格内的矩形、至少 2 个格子；
- 不能与已有合并区域**部分重叠**（完全包含已有区域时按“合并成更大矩形”处理，或将选区限制为空白格子，二选一在实现时固定并在文档写明）；
- 合并/拆分后重新计算容量与图片落位；若容量 < 图片数，按 5.2 处理（多余图片标「未放入」）。

### 5.7 边界与异常清单
| 场景 | 预期行为 |
|---|---|
| 0 张图片 | 显示空状态引导；网格设置仍可编辑；不产生输出 |
| 1 张图片 | 放入第一个区域，其余留空 |
| 图片数 > 容量 | 超出的图片保留在列表并标记「未放入」；状态栏提示；保存只输出已放入的图片 |
| 图片载入失败/损坏 | 沿用现有逻辑：跳过并提示，不影响其他图；网格布局在可用图片上计算 |
| 行列数为 1 | 退化为单行/单列网格，正常工作 |
| 行列数 20×20 | 支持（容量 400 > 图片上限 200，空位留空）；预览可正常生成 |
| 行/列间距 0 | 相邻区域严丝合缝，无 1px 缝隙 |
| 合并后改行列数 | 越界合并自动移除并提示 |
| 超大输出 | 沿用 8000 万像素/32000px 保护，自动缩小并提示 |
| 旧 settings.ini | 缺新键用默认值；非法值 clamp；损坏文件回退默认 |
| 保存/另存为 | 沿用现有逻辑：PNG 保留透明；JPG 透明区域压白底；网格模式无差异 |

### 5.8 合并结构序列化（settings.ini / CLI）
- 格式：`GridMerges=1,1,2,2;3,3,4,3`（1 基坐标，闭区间：`r0,c0,r1,c1`；分号分隔多个合并区域）。
- 读取时：越界/非矩形/重叠/单格的项直接丢弃并 clamp，不报错；最多 200 个合并区域。
- 示例含义：`1,1,2,2` = 左上 2×2 大格；`3,3,3,4` = 第 3 行第 3–4 列横向合并。

## 6. 数据模型与接口变更（开发草案，确认后冻结）

### 6.1 共享模型 `src/Common/Models.cs`（Lead 统一修改）
- `CollageOrientation` 增加 `Grid = 2`（保留 Horizontal=0 / Vertical=1，旧配置兼容）。

  - 单元格显示模式固定为「等比完整显示」（Q3 已确认，本期不加 Cover 设置项）

- `CollageLayout` 可增加网格几何元数据（可选）：`GridRows/GridColumns/CellWidth/CellHeight/RowGap/ColumnGap/Margin`，

### 6.2 布局引擎 `src/Core/LayoutEngine.cs`
- `Compute` 增加 `Grid` 分支；新增内部 `BuildGrid` 与 `GetAutoGridCellSize`（宽/高分别取中位数）。
- 网格版 `Build` 产出：画布尺寸、区域矩形（每个“已放入”的图片一个 `LayoutItem`，`Index`=图片下标）、容量、WasClamped。
- 尺寸保护复用现有 `ComputeAuto`/`ScaleLayout` 思路；`ScaleLayout` 对矩形做边界取整，网格可直接复用。
- 合并集合的解析/校验/容量计算提供公开静态方法（供 UI 预览、设置页、CLI、测试复用），例如
  `GridLayout.ValidateMerges(rows, cols, merges)`、`GridLayout.Capacity(rows, cols, merges)`。

### 6.3 合成器 `src/Core/Compositor.cs`
- 函数签名不变；网格模式下按区域矩形将图片“等比完整显示居中”绘制（横向/纵向路径保持原实现，零回归）。

- 网格模式保存时只解码已放入的图片（性能优化：未放入图片不参与保存）。

### 6.5 命令行 `src/Program.cs`

## 8. 明确不做（控制范围，保持轻量）

| 不做项 | 原因 |
|---|---|
| 自由布局 / 任意拖拽格子大小 / 非矩形（L 形）合并 | 超出“网格”定义，复杂度高 |
| 图片旋转、裁剪编辑、滤镜、描边、文字/水印 | 现有产品不做，另立项 |
| 网格模板库 / 一键九宫格预设（如 1 大 + 4 小） | 可作为后续 P1，本次不做 |
| 拖动图片到“空位”（列表中间插入空位） | 会引入空位数据模型，超出本次需求 |
| 每个格子单独的边距/背景/圆角 | 与统一网格规则冲突 |
| 撤销/重做 | 对调可反向再拖；合并可拆分；暂不引入 |
| Win11 新版一级右键菜单、MSIX 打包 | 沿用 v1 结论，不在本次范围 |

## 10. 需求确认结论（已确认）

> 2026-11-05 用户确认：**Q1–Q10 全部按推荐方案执行**。以下为最终结论，开发与验收以此为准。

| 编号 | 问题 | 确认结论 |
|---|---|---|
| Q1 | 行列是否可分别设置？ | **可以分别设置**：范围各 1–20，默认 3×3（如 3 行 × 4 列） |
| Q2 | 填充顺序？ | **从左到右、从上到下（行优先）**；最后一行未填满留空 |
| Q3 | 单元格内图片如何显示？ | **等比缩放、完整显示、不裁切**；空白用背景色/透明填充；本期不做裁切模式 |
| Q4 | 预览拖动换图规则？ | **拖到另一张图上 → 两张图对调**；拖到空白/无效区域不生效；Esc 取消 |
| Q5 | 合并单元格怎么操作？ | **侧栏「合并单元格…」打开弹窗矩阵编辑器**：拖选矩形 → 合并/拆分/清空所有合并；确定后应用 |
| Q6 | 容量不足（图片多于格子）时？ | **多余图片保留在底部列表并标「未放入」**，状态栏提示；保存只输出已放入的图片 |
| Q7 | 合并结构是否记忆？ | **记忆**：与行列数、间距一起写入设置文件，重启后恢复；提供「清空所有合并」 |
| Q8 | 预览拖动换图范围？ | **横向 / 纵向 / 网格三种模式都支持** |
| Q9 | 网格「自动」输出尺寸的基准？ | **单元格宽/高分别取所有图片宽/高的中位数**；尺寸保护照旧生效 |
| Q10 | 预览是否显示网格辅助线？ | **显示淡淡的单元格边界（仅预览、不写入输出）**，提供开关并记忆 |

### 10.1 其他已确认的默认约定
- 行数/列数范围 1–20，默认 3×3；行间距/列间距默认 12、范围 0–200；外边距沿用 16、范围 0–200。
- 合并区域内部的行/列间距消失（大图连续、无裂缝）；大格内图片居中、完整显示。
- 行列数变化时，仍在范围内的合并保留，越界合并自动移除并提示；容量变化可能导致部分图片「未放入」。
- 图片顺序与合并结构解耦：合并/拆分只改变格子与容量，不打乱图片顺序。
- 版本号 v1.1.0；开发完成后按现有流程构建并安装到本机右键菜单（如不需要安装请说明）。
- 保留“暂不做清单”（第 8 节）中的全部项目：自由布局、模板库、撤销/重做、裁切模式等。
