## 1. 一句话产品定义

一个**免安装、秒开**的 Windows 图片拼接小工具：在资源管理器里选中一张或多张图片，右键 →「拼图」，即可在预览窗口里横向/纵向拼接，随时增删图片、调整间距/边距/背景色与透明度，一键保存为 PNG/JPG。

---

## 2. 典型使用流程

1. 在资源管理器选中 1~N 张图片（可跨文件夹、可混合格式）。
2. 右键 →（Win11 下为「显示更多选项」→）「拼图」。
3. 工具窗口弹出，图片按选择顺序进入底部缩略图栏，右侧是拼接设置，中间是实时预览。
4. 在工具里继续添加（按钮/拖入文件）、删除、拖动排序。
5. 调整横向/纵向、间距、外边距、背景颜色与透明度、输出尺寸（自动/指定宽度/指定高度）、输出格式。
6. 点「保存图片」到默认位置（第一张图所在文件夹），或「另存为…」自选位置。
7. 若工具已打开，再次右键拼图会**追加到当前窗口**（单实例），并弹到前台；点「清空」可开始新项目。

## 3. 功能清单

### P0（首个版本必须）

**右键菜单**
- 仅对图片文件显示「拼图」菜单项，单选/多选均可。
- 菜单项带应用图标；使用当前用户注册表（HKCU），**不需要管理员权限**。
- 安装/卸载脚本；写入哪个目录、如何修复、如何卸载写进 README。
- Windows 11 说明：注册表方式添加的是经典菜单项，位于「显示更多选项」中（详见待确认 Q3）。
- 支持格式：JPG/JPEG、PNG、BMP、GIF（首帧）、TIFF、WebP、HEIC/HEIF（WebP/HEIC 通过系统 WIC 解码器；当前机器已安装 WebP 与 HEIF 扩展，缺失时会给出明确提示）。

**编辑器**
- 单实例：重复右键调起时，把新选图片追加到当前窗口并唤醒窗口，不会开出多个窗口。
- 缩略图列表：显示顺序、序号、缩略图；可拖动排序；可单张删除、清空。
- 添加图片：按钮选择文件；支持从资源管理器拖入文件；支持同时加入多张。
- 横向/纵向两种拼接方式，实时切换。
- 图片间距、外边距分别可调（0–200 px，默认间距 12、外边距 16）。
- 背景颜色可调：颜色选择器 + Alpha 透明度滑块（0–255）。
- 保留每张原图自身的透明度；背景透明度只影响背景/间隙，不会给图片整体加透明度。
- 预览区透明棋盘格底，所见即所得；显示最终输出尺寸。
- 保存 PNG（默认，保留 Alpha）或 JPG（无 Alpha，透明区域按白底合成）。
- 默认保存到第一张图片所在目录，文件名 `拼图_yyyyMMdd_HHmmss.png`；同名自动加序号。
- 设置自动记忆（间距、边距、背景、透明度、排列方式、输出尺寸、输出格式等），下次打开沿用。
- 图片自动应用 EXIF 方向（手机照片不会横躺）。
- 单图也可以打开：保留原图比例，可加边距/背景后保存，也可继续添加。

**性能与轻量**
- 单个 exe，无外部依赖、无安装包框架、无后台常驻服务。
- 冷启动目标：< 400 ms（工具窗口可见，不含图片解码）。
- 预览解码与拼接在后台线程执行，界面不卡顿；连续调整参数做防抖，避免重复计算。
- 预览使用缩略图缓存；保存时才按原图分辨率重新解码合成，兼顾速度与画质。
- 内存与输出尺寸保护：异常超大图/超多图自动限制并提示，不让工具崩溃。

**质量**
- 图片缩放使用高质量插值；避免明显锯齿/糊边。
- 不支持/损坏的文件跳过并给出可读提示，不影响其他图片。
- 保存失败（占用、无权限、路径不存在）有明确提示。

### P1（首版可做，视时间）
- 按文件名自然排序按钮（右键传入顺序可能受 Explorer 影响）。
- 保存后「打开所在文件夹」/「打开图片」快捷操作。
- 快捷键：Ctrl+O 添加、Delete 删除、Ctrl+S 保存、Ctrl+Shift+S 另存为。
- 关于/帮助窗口：版本号、右键菜单修复说明、卸载说明。
- 拖动排序时显示插入位置指示。
- 拖动文件到窗口任意位置添加。

### 暂不做（避免变重）
- 九宫格/自由布局/模板。
- 图片旋转、裁剪、滤镜、边框、阴影、文字、水印。
- 云相册、批量任务、命令行自动化（可保留隐藏的 --compose 测试入口）。
- Win11 新版一级右键菜单（见 Q3；如必须，需要 MSIX 打包 + 证书签名，另行评估）。
- HEIC/WebP（见 Q4）。

## 4. 拼接规则（核心算法）

设图片按顺序为 1..n，宽高为 `(w_i, h_i)`（已按 EXIF 转正），图片间距 `gap`，外边距 `margin`，背景色 `BG`（ARGB）。

### 4.1 横向拼接（默认）
1. 确定统一高度 `H`：
   - 默认「自动」：取所有图片高度 `h_i` 的中位数（单图时即原图高度），保证不做过度的放大/缩小；
   - 也可手动指定（例如 1080）。
2. 每张图等比缩放：`W_i = round(w_i * H / h_i)`，高度统一为 `H`，**不裁切**。
3. 画布：`W = 2*margin + ΣW_i + gap*(n-1)`；`H_canvas = 2*margin + H`。
4. 所有图片垂直居中（高度一致自然居中），水平按顺序排列，间隙和四周填背景色（含 Alpha）。

### 4.2 纵向拼接
与横向对称：统一宽度 `W`（自动=宽度中位数），每张图等比缩放到宽 `W`、高 `round(h_i*W/w_i)`；画布宽度 `W+2*margin`，高度 `2*margin+ΣH_i+gap*(n-1)`。

### 4.3 单图 / 空状态
- 单图：默认不缩放（自动基准=原图对应边），外边距可调，可作加边框/背景用途。
- 空状态：显示引导「点击添加图片，或把图片拖进来」。

### 4.4 尺寸保护
- 输出总像素上限 8000 万，单边上限 32000 px（GDI+ 安全边界内）。
- 超限时自动等比下调输出尺寸，并在状态栏提示「已自动缩小」。
- 原图解码失败、超过 2 亿像素、文件过大等跳过并汇总提示。

## 5. 透明度与颜色规则（重点）

- 输出画布使用 32 位 ARGB。
- 先用背景色（含用户设定的 Alpha）清空画布，再把每张图按 `SourceOver` 叠加；**不对图片整体乘任何全局透明度**，因此每张图原有的 Alpha 完整保留。
- 背景 Alpha=0 时：间隙和四周完全透明（PNG 保存后可见棋盘格/透明）。
- 背景 Alpha 介于 1–254 时：背景半透明，叠在图片下层；图片不透明区域仍然完全不透明。
- 预览：画布下面铺棋盘格，直接展示最终合成效果。
- JPG：没有 Alpha 通道，导出时把最终结果合成到白色底上，并在 UI 提示「JPG 不支持透明，透明区域将填白」。PNG 为默认推荐格式。

## 7. 技术选型

### 7.1 结论：C# + WinForms + .NET Framework 4.8（单文件 exe）

| 方案 | 体积/启动 | 依赖 | 开发成本 | 结论 |
|---|---|---|---|---|
| **C# WinForms / .NET Framework 4.8** | exe 约 100–300 KB；冷启动约 100–300 ms | Win10 1903+/Win11 自带 4.8，无需安装运行时；无需第三方库 | 低 | ✅ 采用 |
| WPF / .NET Framework 4.8 | exe 小；启动约 400–900 ms，内存更高 | 同上 | 中 | 不必要，改用 WinForms |
| .NET 8/9 自包含 WinForms/WPF | 单文件 60–150 MB；启动尚可 | 无运行时依赖但体积大 | 中 | 违背“轻量” |
| .NET 8 框架依赖 | exe 小 | 需要用户装 .NET 8 Desktop Runtime | 中 | 依赖不可控 |
| Python + PySide6 + PyInstaller | 50–150 MB；启动 1–3 s | 打包体积大 | 低 | 不采用 |
| Electron | 100 MB+；启动慢 | 重 | 低 | 不采用 |
| C++ Win32 + GDI+ | exe 最小；启动最快 | 无 | 高（自绘 UI/交互） | 性价比低 |

**为什么不是 .NET 8**：当前机器没有 dotnet SDK/Runtime；自包含发布体积大。系统已有 .NET Framework 4.8（Release 534296），用系统自带编译器即可构建，交付体积最小、启动最快。
**为什么不是 WPF**：本工具 UI 以自绘预览和简单控件为主，WinForms 足够；启动和内存更优。
**构建方式**：使用 Windows 自带 `C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe` 编译（C# 5 语法，支持 async/await），提供 `build.ps1` 一键构建，无需 Visual Studio / dotnet SDK。
**图像引擎**：GDI+（System.Drawing）负责常见格式解码、EXIF 方向、缩放、ARGB 合成、PNG/JPG 编码；WebP/HEIC/HEIF 通过 WIC（WPF `BitmapDecoder`，.NET Framework 自带 WPF 程序集）解码后再交给 GDI+ 合成。不需要第三方 DLL。
**格式依赖说明**：WebP 需要系统安装 Webp Image Extension；HEIC 需要 HEIF Image Extension（当前机器均已安装）。缺少解码器的电脑上会提示安装对应扩展，不影响其他格式。
**单实例**：命名互斥量 + 命名管道（NamedPipeServerStream），第二个实例把文件列表发给第一个实例后退出。
**右键菜单**：HKCU 下写 `SystemFileAssociations\<扩展名>\shell\拼图`（以及图片感知类型），`MultiSelectModel=Player`；命令带 `%1`，由单实例聚合多选文件。详见风险说明。
**设置存储**：`%APPDATA%\LightCollage\settings.ini`，无注册表配置、无数据库。
**资源**：exe 内嵌 Win32 图标；运行时不释放 DLL。

### 7.2 关于右键多选的技术说明（已调研）
- 注册表静态菜单项一次右键多选时，Windows 可能为**每个文件启动一次** exe（采用 `Player` 也一样），且单次最多传约 100 个文件。
- 因此本工具采用**单实例收集器**：每个实例把收到的文件通过命名管道送给首个实例；首实例在 200 ms 窗口内合并所有结果，再统一载入。用户感知是「一次右键 → 一个窗口 → 所有图片」。
- 若实测当前系统一次调用即可传全部文件，同样兼容（收到一个列表直接使用）。
- 可选更优雅的 COM `IExecuteCommand` 方案可做到一次进程收到完整选择，但需注册 LocalServer32 COM 服务器，代码复杂、审计/杀软风险更高；首版不采用，先保证稳定。

### 7.3 右键菜单的现实限制
- 当前系统使用 Win11 新版右键菜单，注册表经典菜单项会收在「显示更多选项」里。
- 要出现在 Win11 新版一级菜单，需要 MSIX 打包 + 代码签名/证书信任（通常要管理员安装证书），与“轻量、免安装”冲突。
- 本方案：**经典菜单 + 免管理员**；README 会写清楚操作路径，并支持一键卸载/修复。
- 如果用户坚持一级菜单，需单独立项评估（可能无法做到完全免管理员/无签名警告）。

## 10. 安装与卸载

- `安装右键菜单.bat`：把 exe 复制到 `%LOCALAPPDATA%\Programs\LightCollage\`，调用 `LightCollage.exe --register` 写 HKCU 菜单（不请求管理员），提示“Windows 11 请点击‘显示更多选项’”。
- `卸载右键菜单.bat`：调用 `--unregister`，删除安装目录；可选保留/删除 `%APPDATA%\LightCollage` 设置。
- 工具内「关于」提供「修复右键菜单」「打开设置目录」。
- 所有注册表操作仅 HKCU，均可逆；不写 HKLM，不改文件关联，不设默认打开方式。

## 11. 已确认决策

- **Q1 拼接缩放规则 = A 等比统一基准**：横向统一高度、纵向统一宽度；默认自动取中位数，可在界面手填数值；保持比例、不裁切，每张图尺寸可能不同。
- **Q2 背景默认值 = A 透明背景**：默认 Alpha=0、输出 PNG；支持任意颜色 + 透明度并记忆；另提供 JPG。
- **Q3 Win11 右键菜单 = 先做经典菜单**：接受在「显示更多选项」中点击「拼图」；免管理员、轻量稳定。后续如有需要再评估 MSIX 一级菜单方案。
- **Q4 图片格式 = B 增加 WebP/HEIC**：在常见格式基础上支持 WebP、HEIC/HEIF；依赖系统 WIC 解码器，缺失时给出明确提示。
- **Q5 默认行为 = 全部接受**：
  1. 背景默认全透明、输出默认 PNG；
  2. 图片间距 12 px、外边距 16 px；基准尺寸默认自动；
  3. 保存默认到第一张图片所在目录，文件名带时间戳；不自动打开图片；
  4. 多选顺序默认按 Explorer 传入顺序，提供「按名称排序」按钮和拖拽排序；
  5. 已打开窗口时再次右键拼图 = 追加到当前项目，不新开窗口（有「清空」按钮）。
