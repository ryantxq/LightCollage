轻拼 LightCollage · 右键图片拼接工具  v1.1.0
=================================================

一、这是什么
------------
一个免安装、秒开的 Windows 图片拼接小工具：
在资源管理器里选中一张或多张图片，右键 →「拼图」，
在预览窗口里横向/纵向/网格拼接，随时增删图片、调整间距/边距/背景色与透明度，
一键保存为 PNG/JPG。单个 exe，无需安装 .NET 以外的任何运行库。

二、系统要求
------------
· Windows 10（1903 及以上）/ Windows 11；.NET Framework 4.8（Win10 1903+ 与 Win11 系统自带）
· 无需管理员权限；只写当前用户注册表（HKCU）
· 不联网、不写系统目录、不常驻后台、无外部 DLL
· WebP / HEIC / HEIF / AVIF 通过 Windows 系统 WIC 解码器读取：
  - WebP：需要系统安装「Webp Image Extension」（Win11 通常已装）
  - HEIC/HEIF：需要「HEIF 图像扩展」（以及部分机器需要「HEVC 视频扩展」）
  - AVIF：需要系统对应的 AV1/HEIF 解码扩展
  缺少扩展时工具会给出中文提示，不影响其他格式。

三、安装（右键菜单）
--------------------
1. 把整个「轻拼」文件夹解压到任意位置（不要只复制 exe，安装脚本需要和 exe 在一起）
2. 双击「安装右键菜单.bat」
   - 程序会被复制到：%LOCALAPPDATA%\Programs\LightCollage\
   - 右键菜单写入当前用户注册表，不需要管理员确认
3. 看到「[完成] 右键菜单安装成功！」即可使用

Windows 11 注意：
  系统默认右键菜单是精简版，注册表方式添加的「拼图」在「显示更多选项」里。
  操作：选中图片 → 右键 → 点最下面的「显示更多选项」→「拼图」。
  这属于 Win11 的机制；若要出现在一级菜单，需要 MSIX 打包与代码签名，本工具选择轻量方案。

四、使用
--------
1. 在资源管理器选中一张或多张图片（可跨文件夹、可混合格式）
2. 右键 →（Win11：显示更多选项 →）「拼图」
3. 在窗口里：
   · 左侧预览区实时显示拼接效果（透明棋盘格底 = 透明区域）
   · 底部缩略图栏：可拖动排序、单张删除、清空
   · 右侧设置：拼接方式（横向排列 / 纵向排列 / 网格）、间距、外边距、
     背景颜色 + Alpha 透明度 0–255、输出尺寸（自动 / 指定宽度 / 指定高度）、输出格式 PNG/JPG
   · 数字框（间距/边距/行列数/输出尺寸）可点击后用键盘输入，回车确认，Esc 取消
   · 输出尺寸只填宽度或高度其中一项，另一项按拼图比例自动计算
   · 自动尺寸取所有图片高度/宽度的中位数，避免个别超大/超小图片带偏整体
   · 点「保存图片」保存到第一张图片所在文件夹（文件名：拼图_年月日_时分秒.png，同名自动加序号）
   · 也可「另存为…」自选位置

4. 网格拼接（v1.1 新增）：
   · 右侧「拼接方式」选「网格」，可设置行数、列数（各 1–20）和行间距、列间距（各 0–200 px）
   · 图片按从左到右、从上到下的顺序自动填充；没填满的格子留空（显示背景/透明）
   · 点「合并单元格…」打开网格合并编辑器：在格子矩阵上拖选一个矩形区域，
     点「合并所选」即可把相邻格子合并成一个矩形大格；大格只放 1 张图，其余图片继续按顺序往后填
   · 已合并的大格可在编辑器中「拆分所选」或「清空所有合并」
   · 合并会减少总容量（容量 = 格子数 − 合并省下的格数）；图片数超过容量时，
     多余图片仍保留在底部列表并标「未放入」，状态栏会提示；增加行列/拆分合并即可恢复
   · 「显示网格辅助线」只在预览里显示淡淡的格子边界，不会写入保存的图片
   · 网格模式下同样支持间距、外边距、背景/透明度、输出尺寸与 PNG/JPG

5. 预览拖动换图（v1.1 新增，横向/纵向/网格都可以）：
   · 在左侧预览中按住一张图片，拖到另一张图片上松开，两张图片即对调位置
   · 底部缩略图的顺序与序号会同步更新
   · 拖到空白格/空白区域不会生效；按 Esc 可取消拖动；加载/保存过程中暂不可用

6. 工具已经打开时，再次右键「拼图」会把新图片追加到当前窗口并唤醒窗口（不会开第二个窗口）。
7. 设置会自动记忆（含网格行列数、行/列间距、合并结构、辅助线开关）：
   %APPDATA%\LightCollage\settings.ini

五、快捷键
----------
  Ctrl+O          添加图片
  Delete          删除当前选中的缩略图
  Ctrl+S          保存图片
  Ctrl+Shift+S    另存为
  鼠标拖动缩略图    调整拼接顺序
  鼠标拖动预览图片  与另一张图片对调顺序（v1.1）
  Esc             取消预览拖动 / 合并编辑器拖动

六、格式与透明度
----------------
· 支持：JPG/JPEG/JPE、PNG、BMP、GIF（取首帧）、TIFF、WebP、HEIC/HEIF、AVIF、JFIF
· 手机照片会自动应用 EXIF 方向，不会横躺
· 背景透明度只影响背景与间隙，不会给图片整体加透明度；原图自带的透明像素会保留
· PNG 支持透明（推荐）；JPG 不支持透明，透明区域会按白色底合成
· 输出尺寸保护：单个方向超过 32000 px 或总像素超过 8000 万时会自动等比缩小并提示
· 中位数：把所有图片的高度（横向）、宽度（纵向）或宽/高（网格单元格）排序后取中间值，避免个别超大/超小图片影响整体
· 网格：每张图在所属格子/合并大格内等比缩放、完整显示、居中，不裁切也不拉伸；
  格子比例与图片不一致时，剩余空间用背景色/透明填充

七、卸载
--------
双击「卸载右键菜单.bat」：
  · 删除当前用户右键菜单中的「拼图」项（含全部图片扩展名）
  · 删除安装目录 %LOCALAPPDATA%\Programs\LightCollage
  · 询问是否删除设置目录（默认保留，方便以后重装沿用）
所有注册表改动都在 HKCU，可逆，不改文件关联、不写 HKLM。

八、常见问题
------------
Q：右键菜单里找不到「拼图」？
A：① Windows 11 请先点「显示更多选项」；
   ② 确认选中的是支持的图片文件（文本/压缩包等不会显示）；
   ③ 同时选中了多种格式时，菜单依赖系统「图片」感知类型，仍应显示；
      若个别情况不显示，可先取消多选逐个操作，或选中同一扩展名的图片；
   ④ 刚安装完菜单没有立刻出现：等几秒或重新打开一个资源管理器窗口；
   ⑤ 还不行就再运行一次「安装右键菜单.bat」修复。

Q：双击右键菜单里的「拼图」没反应 / 报找不到程序？
A：通常是 exe 被移动或删除。重新运行「安装右键菜单.bat」即可把菜单指向新位置。

Q：WebP / HEIC 图片打不开？
A：系统缺少对应解码扩展。请到 Microsoft Store 安装
   「Webp Image Extension」或「HEIF 图像扩展」后重试；其他格式不受影响。

Q：保存 JPG 后透明背景变白了？
A：JPG 本身不支持透明通道，这是正常行为；需要透明请保存为 PNG（默认格式）。

Q：多选图片会打开多个窗口吗？
A：不会。工具是单实例的：后启动的实例把图片转交给已打开的窗口后自动退出。

Q：网格合并后图片变少了 / 提示「未放入」？
A：合并单元格会减少容量；图片数超过容量时，多余图片会保留在底部列表并标「未放入」，不会被删除。
   可增加行列、拆分合并，或删掉部分图片后恢复；保存时只输出已放入网格的图片。

Q：网格模式会把图片裁掉或拉变形吗？
A：不会。图片按等比缩放完整显示并居中，不裁切、不拉伸；格子比例不合适时可用行/列数或间距调整。

Q：在预览里拖动图片没反应？
A：需要按住一张图片拖到另一张图片上再松开（对调）；拖到空白格/空白区域不生效，
   加载/保存过程中也不可拖动；按 Esc 可取消。底部缩略图栏的拖动仍是插入排序。

Q：杀毒软件提示 / SmartScreen 警告？
A：本工具是本地编译的未签名程序，可能触发未知发布者提示。
   选择「更多信息 → 仍要运行」即可；也可以自行查看并编译源码。

Q：设置保存在哪里？如何恢复默认？
A：%APPDATA%\LightCollage\settings.ini，删除该文件即恢复默认设置。

Q：卸载后菜单还有残留？
A：重新运行「卸载右键菜单.bat」。仍残留时可手动删除：
   HKCU\Software\Classes\SystemFileAssociations\（各图片扩展名）\shell\LightCollage
   HKCU\Software\Classes\SystemFileAssociations\image\shell\LightCollage
   （只删本工具的 LightCollage 项即可，不要删除整个 SystemFileAssociations）
